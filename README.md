# 📌 Featured Projects

### 📚 Longbox

**Comic Store / Reader · Android + Ktor Backend · Open Source**

A comic experience built around one question:

> **Can browsing comics feel physical instead of digital?**

🎨 Custom Canvas-rendered comic aisle with perspective geometry, Bézier curves and animated shelf transitions.

⚙️ **Backend:** `Ktor` `MongoDB` `JWT Refresh Rotation` `Mutex Rate Limiter` `Caffeine Cache` `Sentry` `Railway`

📱 **Android:** `Jetpack Compose` `Paging 3` `RemoteMediator` `Room` `Offline First`

🔗 [Repository](https://github.com/Amaanprobably/longbox-backend)

---

### ⚡ PokeDex

**Offline-First Pokédex · Open Source**

A Pokédex built around fast local access and minimal footprint.

🗃️ **1,300+ Pokémon** with indexed offline search and smooth scrolling.

⚙️ `Room` `Paging 3` `RemoteMediator` `GraphQL`

🧪 **30+ unit & integration tests** with JUnit, MockK and Turbine.

📦 **Under 10 MB APK**

🔗 [Repository](https://github.com/Amaanprobably/PokeDex)

---

### 💪 FitFlow

**Fitness Logging & Tracking · Android**

A fitness application built end-to-end with a focus on custom visualization.

📊 Animated ring charts and Bézier-curve performance graphs built directly with **Canvas / DrawScope** rather than a charting library.

🎨 Designed and shipped from UI through release build.
